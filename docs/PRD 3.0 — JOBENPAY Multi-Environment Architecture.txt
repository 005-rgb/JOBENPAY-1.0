# PRD 3.0 (REVISI 2.0) — JOBENPAY Multi-Environment Architecture
## Perfect Isolation: Global Entities vs. Environment-Specific Entities

**Versi:** 2.0 (Major Revision — Fixed Global Settings Flaw)
**Tanggal:** 8 November 2026
**Basis:** PRD 1.2–2.0 + Audit Logika Multi-Environment
**Prinsip Kunci:** **Satu Organisasi, Dua Environment.** Pengaturan umum (Profil Perusahaan, Anggota Tim, Billing) bersifat **GLOBAL**. Data operasional (Agen, Mandat, Transaksi, Uang) bersifat **ENVIRONMENT-SPECIFIC** (terpisah antara Sandbox dan Live).

---

## 0. ATURAN EMAS (NON-NEGOTIABLE)

1. **Pemisahan Entitas (Global vs Env):** Tabel `organizations`, `users`, dan `memberships` **DILARANG** memiliki kolom `environment`. Tabel operasional (`agents`, `mandates`, `transaction_intents`, `ledger_entries`, dll.) **WAJIB** memiliki kolom `environment`.
2. **Konsistensi Tim:** User yang diundang ke Organisasi "Acme Corp" dapat mengakses Sandbox dan Live menggunakan kredensial login yang sama.
3. **Isolasi Total Data Operasional:** Data Agen, Mandat, dan Uang di Sandbox **TIDAK BOLEH** bocor atau terlihat di Live (dan sebaliknya).
4. **Kredensial Terpisah:** PayPal Client ID/Secret untuk Sandbox dan Live disimpan di tabel terpisah yang memiliki kolom `environment`.
5. **UI Wajib Menampilkan Environment Aktif:** Banner dan Toggle wajib ada di semua halaman operasional.
6. **Fail-Closed:** Jika route operasional diakses tanpa header `X-Jobenpay-Environment`, sistem menolak dengan `400 ENVIRONMENT_HEADER_MISSING`.
7. **Coverage 100%** untuk *service* yang menangani isolasi environment.
8. **Zero Ambiguity:** Prompt untuk AI Builder harus eksplisit mengenai file mana yang harus dihapus kolom `environment`-nya.

## 2. SKEMA DATA (REVISI MIGRASI)

**File:** `server/migrations/040_environment_foundation_v2.sql`

```sql
BEGIN;

-- 2.1 Bersihkan Skema Lama (Drop kolom environment dari tabel Global)
ALTER TABLE organizations DROP COLUMN IF EXISTS environment;
ALTER TABLE users DROP COLUMN IF EXISTS default_environment;
ALTER TABLE memberships DROP COLUMN IF EXISTS environment;
ALTER TABLE billing_subscriptions DROP COLUMN IF EXISTS environment;

-- 2.2 Pastikan Tabel Operasional Memiliki Environment
-- (Jika sebelumnya sudah ada, query ini idempoten)
ALTER TABLE agents ADD COLUMN IF NOT EXISTS environment environment_type NOT NULL DEFAULT 'SANDBOX';
ALTER TABLE mandates ADD COLUMN IF NOT EXISTS environment environment_type NOT NULL DEFAULT 'SANDBOX';
ALTER TABLE payees ADD COLUMN IF NOT EXISTS environment environment_type NOT NULL DEFAULT 'SANDBOX';
ALTER TABLE transaction_intents ADD COLUMN IF NOT EXISTS environment environment_type NOT NULL DEFAULT 'SANDBOX';
ALTER TABLE transaction_legs ADD COLUMN IF NOT EXISTS environment environment_type NOT NULL DEFAULT 'SANDBOX';
ALTER TABLE ledger_entries ADD COLUMN IF NOT EXISTS environment environment_type NOT NULL DEFAULT 'SANDBOX';
ALTER TABLE ledger_heads ADD COLUMN IF NOT EXISTS environment environment_type NOT NULL DEFAULT 'SANDBOX';
ALTER TABLE documents ADD COLUMN IF NOT EXISTS environment environment_type NOT NULL DEFAULT 'SANDBOX';

-- 2.3 RLS (Row Level Security) HANYA untuk Tabel Operasional
ALTER TABLE agents ENABLE ROW LEVEL SECURITY;
ALTER TABLE mandates ENABLE ROW LEVEL SECURITY;
ALTER TABLE payees ENABLE ROW LEVEL SECURITY;
ALTER TABLE transaction_intents ENABLE ROW LEVEL SECURITY;
ALTER TABLE ledger_entries ENABLE ROW LEVEL SECURITY;

CREATE POLICY agents_env_isolation ON agents
  FOR ALL USING (environment = current_setting('app.current_environment', true)::environment_type);

CREATE POLICY mandates_env_isolation ON mandates
  FOR ALL USING (environment = current_setting('app.current_environment', true)::environment_type);

-- (Lakukan hal yang sama untuk payees, transaction_intents, ledger_entries)

-- 2.4 Trigger: Mencegah Agent Sandbox dipakai di Live
CREATE OR REPLACE FUNCTION check_agent_environment() RETURNS TRIGGER AS $$
DECLARE agent_env environment_type;
BEGIN
  SELECT environment INTO agent_env FROM agents WHERE agent_id = NEW.agent_id;
  IF agent_env IS NULL THEN RAISE EXCEPTION 'Agent % not found', NEW.agent_id; END IF;
  IF agent_env <> NEW.environment THEN
    RAISE EXCEPTION 'Environment mismatch: agent=% transaction=%', agent_env, NEW.environment;
  END IF;
  RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER trg_check_agent_environment BEFORE INSERT OR UPDATE ON transaction_intents
FOR EACH ROW EXECUTE FUNCTION check_agent_environment();

COMMIT;
```

## 3. UPDATE SERVICE LAYER

### 3.1 Organization Service (GLOBAL - Tanpa Environment)

```javascript
// server/src/services/organization_service.js
// @ts-check
import { pool } from '../db/pool.js';

/**
 * Mengambil profil organisasi. TIDAK membutuhkan environment header.
 * Data ini sama di Sandbox dan Live.
 */
export async function getOrgProfile(orgId) {
  const result = await pool.query(
    `SELECT org_id, display_name, legal_name, logo_url, website_url, address 
     FROM organizations WHERE org_id = $1`,
    [orgId]
  );
  return result.rows[0];
}
```

### 3.2 Agent Service (OPERASIONAL - Wajib Environment)

```javascript
// server/src/services/agent_service.js
// @ts-check
import { pool } from '../db/pool.js';
import { AppError } from '../lib/errors.js';

/**
 * Mengambil daftar agen. WAJIB menyertakan environment.
 * Agen Sandbox tidak akan muncul di Live.
 */
export async function listAgents(orgId, environment) {
  if (!environment || !['SANDBOX', 'LIVE'].includes(environment)) {
    throw new AppError('INVALID_ENVIRONMENT', 400);
  }
  
  const result = await pool.query(
    `SELECT agent_id, name, status FROM agents 
     WHERE org_id = $1 AND environment = $2
     ORDER BY created_at DESC`,
    [orgId, environment]
  );
  return result.rows;
}
```

## 4. API CONTRACTS (MIDDLEWARE ROUTING)

**File:** `server/src/middleware/environment.js`

```javascript
// @ts-check
import { AppError } from '../lib/errors.js';

export function environmentMiddleware(req, res, next) {
  // Pengecualian: Route Global tidak butuh environment header
  const globalRoutes = [
    '/api/v1/org/profile',
    '/api/v1/org/members',
    '/api/v1/billing',
    '/api/v1/auth/me'
  ];
  
  if (globalRoutes.some(route => req.path.startsWith(route))) {
    return next();
  }

  // Untuk route operasional, header WAJIB ada
  const env = req.headers['x-jobenpay-environment'];
  if (!env || !['SANDBOX', 'LIVE'].includes(env)) {
    return next(new AppError('ENVIRONMENT_HEADER_MISSING', 400));
  }

  req.environment = env;
  next();
}
```

## 5. UI & FRONTEND BEHAVIOR

### 5.1 Environment Toggle Context
Di React, buat `EnvironmentContext` yang menyimpan state `currentEnvironment` ('SANDBOX' | 'LIVE').

### 5.2 Route Guard
- Saat mengakses `/organization` (Business Tools), Axios/fetch **TIDAK** mengirim header `X-Jobenpay-Environment`.
- Saat mengakses `/agents`, Axios/fetch **WAJIB** mengirim header `X-Jobenpay-Environment: SANDBOX` atau `LIVE` sesuai state.

### 5.3 Visual Indicator
- Saat di Sandbox: Banner biru "SANDBOX MODE".
- Saat di Live: Banner merah "LIVE MODE — Real money".
